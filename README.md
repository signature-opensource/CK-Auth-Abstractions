# CK-Auth-Abstractions

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-Auth-Abstractions.svg)](LICENSE)

Contains [CK.Auth.Abstractions](CK.Auth.Abstractions/README.md): the `IUserInfo` and
`IAuthenticationInfo` contracts, the `AuthLevel` scale, and the extensible
`StdAuthenticationTypeSystem` that converts them to claims, JSON and binary.

| Package | Description | Latest stable |
|---------|-------------|---------------|
| [CK.Auth.Abstractions](CK.Auth.Abstractions/README.md) | Authentication contracts and their standard immutable implementation. | [![nuget](https://img.shields.io/nuget/v/CK.Auth.Abstractions.svg?label=CK.Auth.Abstractions)](https://www.nuget.org/packages/CK.Auth.Abstractions/) |
